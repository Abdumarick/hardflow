# 08 Future Features

These items should not delay the first production core unless explicitly promoted to Version 1.

## Version 1.5 candidates
- Full barcode scanning/label workflows.
- Advanced stock transfer UI and branch operations.
- Store/rack/shelf product locations.
- Advanced reporting and analytics.
- Enhanced notification channels.
- More receipt/EFT/POS printer integrations.
- Two-factor authentication rollout.
- Recurring expenses.

## Version 2 candidates
- Full offline-first operation and synchronization.
- WhatsApp/SMS transactional integrations.
- External accounting integrations.
- Additional APIs and integrations.
- Advanced multi-currency transactions/exchange-rate handling.
- Subscription/billing plans for SaaS commercialization.

## Architecture readiness
Future readiness does not mean implementing speculative complexity now. Preserve clear extension points and avoid schema decisions that unnecessarily block these features.
